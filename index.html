How to Use the Simulator

  • Enter numbers separated by commas (e.g., 5,3,8,6).
  • Select a sorting algorithm from the dropdown.
  • Click "Start" to visualize the sorting process.
  • Use "Pause" to pause/resume the animation.
  • Use "Reset" to clear and start again.
  • Use the speed slider to adjust animation speed.
